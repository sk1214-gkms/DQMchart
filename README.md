# 配合チャートメーカー

ドラゴンクエストモンスターズの配合チャートを作成するWebアプリ。
**DQM3** と **イルルカSP** に対応（配合方式の違う2タイトルを同じエンジン基盤で扱う）。
次回作 DQM4 は DQM3 と同方式と想定し、データを足すだけで対応できる設計にしている。

## 起動

```
cd web
npm ci
npm run dev   # → http://localhost:3000
```

## テスト・品質ゲート

```
cd web
npm test                              # vitest（配合ルールエンジン＋実データ検証）
npm run lint                          # eslint
npm run typecheck                     # next typegen + tsc --noEmit
npm run build                         # 本番ビルド検証
node tools/data-report.mjs [titleId]   # マスタデータの網羅性レポート（既定: dqm3）
```

## 設定

`web/.env.example` をコピーして `web/.env.local` を作る。
現時点で必須の環境変数はない（Supabase導入時に追記予定）。

## 主な機能

| 画面 | 内容 |
|---|---|
| `/simulate` | 配合シミュレータ: 親2体 → 子候補（配合方式に応じて計算＋特殊配合） |
| `/auto` | 自動チャート生成: 目標モンスターから配合ツリーを逆算。配合なしで入手できるモンスターが葉になる |
| `/editor` | 手動チャートエディタ: 配置・接続して配合計画を作る。ルールエンジンで成立判定 |

共通の使い勝手:

- 画面上部のタイトル切替で対応タイトルを選ぶ（設定はブラウザに保存）
- モンスター選択は名前・系統・ランクで絞り込める
- フロー図は縦（親が上）／横（親が左）を切り替え可能
- チャートはPNG画像として保存できる（表示位置や拡大率に関係なく全体を書き出す）
- 自動生成では「▶」が付いた葉ノードを押すと、そのモンスターを配合で作る手順を展開できる

## 構成

### 配合ルールエンジン `web/src/lib/engine/`

UI非依存の純粋ロジック。タイトルごとに `BreedingRuleset` 実装を追加し `registry.ts` に登録する。
UIやチャート描画は方式の違いを知らないので、**新タイトル対応で画面側の変更は不要**。

**DQM3方式** (`dqm3.ts`)
- 通常配合は「系統ペア×ランク」テーブル参照。親のランクが違えば両方のランクの表から選べる
- 親自身の種族も常に子候補に含まれる（同系統同士では親のどちらかしか生まれない）
- 通常配合では親よりランクの高い子は生まれず、ランクアップは特殊配合のみ
- 4体配合は祖父母4体で決まるため親2体だけでは判定できない（`quadCandidates` で扱う）

**位階配合方式** (`tier.ts`／イルルカSPなど)
- 全モンスターに通し順の「位階」があり、子は位階の並びから決まる
- 同系統配合 → 強いほうの親より位階が1つ上の、同じ系統のモンスター
- 異系統配合 → ①父の系統で強い親の1つ上 ②母の系統で強い親の1つ上 ③系統組み合わせ表で決まる別系統で、**弱いほうの親**の1つ上
- 系統の最上位を超える子は生まれない（位階の打ち止め）

逆算プランナーはどちらの方式も、入手できるモンスターを起点にコストが下がらなくなるまで
繰り返し緩和する方式（最短経路の緩和法と同じ考え方）で最小手数を求める。
配合の依存は循環しうるため、素朴な深さ優先探索では到達可能な経路を取りこぼす。

### マスタデータ `web/src/data/titles/`

| タイトル | 方式 | 規模 | 到達率 |
|---|---|---|---|
| DQM3 (`dqm3.json`) | DQM3方式 | モンスター526体／通常配合126／特殊配合372 | 100% |
| イルルカSP (`iruruka.json`) | 位階配合 | モンスター902体／系統表28／特殊配合608 | 98.8% |

- 攻略サイトから収集した実データ。誤りに気づいたらJSONを直接修正してよい
- 配合以外の入手手段は `acquisition` で区別（`wild` 野生／`egg` タマゴ限定／`event` イベント・他国マスター等）
- 位階配合タイトルの `tier` は**ランク順とは一致しない**。実際の位階番号を使うこと
  （イルルカSPではビーンファイター・りゅうはかせ・魔勇者アンルシアが上位ランク帯に食い込む）

### その他

- `web/src/lib/storage.ts` — チャート保存の抽象。現在はlocalStorage実装。
  Supabase（Googleログイン・アカウント別保存）導入時に実装を差し替える
- `web/src/components/ChartImageButton.tsx` — チャートのPNG書き出し。
  DOMを画像化するライブラリはReact Flowの配合線を取り込めないため、
  ノードと線からSVGを組み立ててcanvasでPNG化している
- `設計/配合チャートアプリ_全体構成.drawio` — アーキテクチャ・データモデル図（シートがバージョン履歴）
